# zmanager-core

Core archive, authentication, and policy engine for ZManager.

Part of the [ZManager](https://github.com/tzap-org/zmanager) universal file archiving suite.

## Overview

`zmanager-core` provides high-performance compression, broad format extraction (ZIP, 7z, TAR, TZAP, RAR, Apple Archive, etc.), safe extraction rules (guarding against path traversal, symlink escapes, and zip bombs), and unified progress reporting.

For full documentation and feature overview, visit the [ZManager repository](https://github.com/tzap-org/zmanager).
