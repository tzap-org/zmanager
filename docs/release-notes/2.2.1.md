# ZManager CLI 2.2.1 Release Notes

ZManager CLI 2.2.1 updates the TZAP cryptography stack and tightens archive and hosted identity handling across platforms.

## Highlights

- Update TZAP crates to 0.2.9 and build against OpenSSL 3.5.9 with TZAP's pinned upstream RSA-PSS provider alias patch.
- Harden RAR archive parsing, extraction, and recovery paths.
- Canonicalize hosted certificate challenges with RFC 8785 before signing.
- Expand cross-platform release checks for static OpenSSL, offline operation, and package contents.

## Upgrading

The existing CLI commands and archive formats remain compatible. The release includes updated native cryptography libraries in its platform packages.
