# ZManager CLI 2.3.0 Release Notes

ZManager CLI 2.3.0 updates the TZAP engine and strengthens release provenance
and macOS distribution.

## Highlights

- Update TZAP crates to 0.3.0. TZAP preserves existing destinations during
  atomic overwrite, limits selected-file restore work to the requested members,
  and signs and notarizes its macOS binaries.
- Sign and notarize ZManager's macOS CLI binaries before publishing them.
- Pin every sibling build input to a reviewed commit and use that same snapshot
  across release packages.
- Improve static OpenSSL builds and cross-platform release packaging.

## Upgrading

The command-line interface and archive formats remain compatible. TZAP 0.3.0
improves overwrite safety and selected-file restore behavior.
