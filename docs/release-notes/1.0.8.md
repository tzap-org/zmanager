# ZManager CLI 1.0.8 Release Notes

ZManager CLI 1.0.8 brings password-based encryption and decryption support for Apple Encrypted Archives (`.aea`), expanded metadata column tracking across all backends, and platform cross-compilation fixes.

## Highlights

- **Apple Archive Encryption Support**: Added password-based encryption (`.aea`) support using native Apple Encrypted Archive APIs (`AEAContextSetFieldBlob` with SCRYPT key derivation and `AEAContextCreateWithEncryptedStream`).
- **Apple Archive Extension Recognition**: Added `.aea` extension matching for listing, testing, and extraction subcommands across CLI and FFI boundaries.
- **Expanded Metadata Columns**: Added portable metadata tracking for `created` (CTM), BSD/macOS file `flags` (FLG), `crc` checksums, POSIX `uid`, `gid`, `owner`, `group`, and `link_target` across Apple Archive, 7z, TZAP, and libarchive backends.
- **Cross-Platform Stubs & Safety**: Updated non-Apple platform fallback stubs to maintain API signature symmetry across Linux, macOS, and Windows targets.
- **CI Dependency Sync**: Updated `tzap-rev.txt` commit hash and synchronized `Cargo.lock` with `tzap-core v0.1.12`.

## Known Backend Limits

- Creation is intentionally limited to ZIP, TAR.ZST, TZAP, 7z, and TGZ.
- Apple Archive support (reading/writing `.aar` and `.aea`) is available exclusively on macOS and iOS targets.
- Editing an existing archive in place is not supported. Extract, modify, and create a new archive instead.
- RAR creation is not supported.
- Raw single-file streams extract to one output file; they are not archive containers.
- `--to-stdout` is for selected regular file data, not directories, links, or special entries.
